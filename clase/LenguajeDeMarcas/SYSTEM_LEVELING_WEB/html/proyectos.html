SYSTEM LEVELING APP

Esto es un proyecto que actualmente esta activo y en desarrollo continuo ya que es uno de los principales proyectos Aunque actualmente no este desarrollado al 100% este se puede ver su progreso en GitHub.

¿Que es?

SYSTEM LEVELING APP es una aplicacian para poder registrar habitos cotidianos ademas de que esta esta gamificada. Tambien esta cuenta con un pequeño juego integrado el cual estara siempre enfocado en la mejora del usuario

SYSTEM LEVELING WEB

Este proyecto trata de una web con HTML5 CSS y JavaScript en la cual se habla sobre SYSTEM LEVELING.

¿Que es?

Es una web en la cual se habla sobre que es system leveling y cuales son sus proyectos cual es su objetivo/mision etc

SYSTEM LEVELING MARKUP LENGUAGE

Este proyecto trata de un lenguaje de marcas enfocado en la transmision de datos como XML y JSON

¿De donde surge?

El proyecto de SYSLML (System Leveling Markup Lenguage) nace del trabajo del RA1 de lenguaje de marcas en el cual se pedia crear un lenguaje de marcas inventado. Al estar metido planteando el proyecto de system leveling app se me ocurrio la idea de hacer un lenguaje de marcas para dicho trabajo enfocado en System leveling.
