# 1 EXCEPCIONES
Sea el siguiente codigo:

`class EjemploExcepcion {
    public static void main(String[] args) {
        String numero = "a";
        int n = Integer.parseInt(numero);
        System.out.print(n);
    }
}`

Si se ejecuta se optiene el error:

Exception in thread "main" java.lang.NumberFormatException: For input string: "a"
        at java.base/java.lang.NumberFormatException.forInputString(NumberFormatException.java:65)
        at java.base/java.lang.Integer.parseInt(Integer.java:652)
        at java.base/java.lang.Integer.parseInt(Integer.java:770)
      **at EjemploExcepcion.main(EjemploExcepcion.java:4)**
La parte en que no esta en negrita nos indica el error que se ha producido y la parte que esta en negrita nos indica en que linea se ha producido el error (en la linea 4).

Java indica los errores poniendoles un nombre al que se le denominara excepcion. En este caso el error es "NumberFormatException".

Cuando se produce un error, hay estructuras para controlar el error

# 2 try-catch

La estructura "try-catch" permite controlar errores. Su sintaxis es:

`try {
    // Codigo que puede generar errores
} catch (Nombre_de_la_excepcion1 e) {
    // Codigo para tratar el error
} catch (Nombre_de_la_excepcion2 e) {
    // Codigo para tratar el error
} catch (Nombre_de_la_excepcion3 e) {
    // Codigo para tratar el error
}`

## EJEMPLO:
`class EjemploExcepcion {
    public static void main(String[] args) {
        String numero = "a";
        try {
            int n = Integer.parseInt(numero);
            System.out.print(n);
        } catch (NumberFormatException e) {
            System.out.print("La entrada no es un numero");
        }
    }
}`

La variable "e" almacena datos del error. Se puede mostrar:

`class EjemploExcepcion {
    public static void main(String[] args) {
        String numero = "a";
        try {
            int n = Integer.parseInt(numero);
            System.out.print(n);
        } catch (NumberFormatException e) {
            System.out.println("La entrada no es un numero");
            System.out.println("El error es " + e);
        }
    }
}`

El error se puede ignorar o se puede pedir que muestre la "traza" que son todas las lineas de codigo que se han visto envueltas en el error:

`class EjemploExcepcion {
    public static void main(String[] args) {
        String numero = "a";
        try {
            int n = Integer.parseInt(numero);
            System.out.print(n);
        } catch (NumberFormatException e) {
            System.out.println("La entrada no es un numero");
            e.printStackTrace();
        }
    }
}`

# 3 Ejemplo de lectura y escritura de archivos

## Para escribir archivos en Java se va a usar el siguiente codigo:

`
import java.nio.file.Files;
import java.nio.file.StandardOpenOption;
import java.nio.file.Path;

// Para escribir texto en un archivo
String texto = "Hola mundo";
String nombreArchivo = "ejemplo.txt";
Files.write(Path.of(nombreArchivo), texto.getBytes("utf-8"), StandardOpenOption.CREATE);
`

## Para leer un archivo

`
import java.nio.file.Files;
import java.nio.file.StandardOpenOption;
import java.nio.file.Path;

// Para  leer un archivo
String nombreArchivo = "ejemplo.txt"
String leido = new String(File.readAllBytes(Path.of(nombreArchivo)), "utf-8");
System.out.println(leido);
`

El compilador nos indica que hasta que no se ponga un try-catch capturando las excepciones, no compila el programa.

## Capturamos los errores:
`
import java.nio.file.Files;
import java.nio.file.StandardOpenOption;
import java.nio.file.Path;

class EjemploEscribir {
    public static void main(String[] args) {
       // Para escribir texto en un archivo
       try {
            String texto = "Hola mundo";
            String nombreArchivo = "ejemplo.txt";
            Files.write(Path.of(nombreArchivo), texto.getBytes("utf-8"), StandardOpenOption.CREATE);
        } catch(UnsupportedEncodingException e) {
            e.printStackTrace();
       } catch(IOException e) {
            e.printStackTrace();
       }
    }
}`

# 4 LA CLASE EXCEPTION
La clase Exception captura todas las excepciones. **NO SE RECOMIENDA SU USO.**

`
import java.nio.file.Files;
import java.nio.file.StandardOpenOption;
import java.nio.file.Path;

class EjemploEscribir {
    public static void main(String[] args) {
       // Para escribir texto en un archivo
       try {
            String texto = "Hola mundo";
            String nombreArchivo = "ejemplo.txt";
            Files.write(Path.of(nombreArchivo), texto.getBytes("utf-8"), StandardOpenOption.CREATE);
        } catch(Exception e) {
            e.printStackTrace();
        }
    }
}
`
